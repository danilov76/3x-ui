# Обновление панели и нод из UI

Начиная с `tunnels-3.8.5-patch5`, существующие кнопки обновления панели и нод
используют стабильные релизы `danilov76/3x-ui`. HTTP API и выбор нод не меняются.
Обновлятор встроен в бинарник; скрипт оригинального проекта не скачивается.

Для существующих установок patch4 и старше один раз установите patch5 штатным
`deploy.py` из архива форка. Это нужно на каждой ноде: мастер только вызывает
API обновления, исполняет обновление сама нода. До установки patch5 кнопка на
старой ноде по-прежнему использует оригинальный проект.

Поддерживаются Linux amd64, systemd, SQLite и стандартные пути установки.
Python 3 обязателен. Dev-канал намеренно отклоняется до начала обновления.
PostgreSQL и нестандартные пути требуют ручной установки.

Выбирается latest stable release с тегом `tunnels-3.8.5-patchN` (N >= 5).
Архив `3x-ui-tunnels-linux-amd64.tar.gz` проверяется по SHA256 из GitHub API.
Отсутствующий digest, несовместимый тег или небезопасные пути в архиве
останавливают обновление до изменения установки. Оригинальный релиз не является
резервным источником.

Архив должен содержать каталог `3x-ui-tunnels-release-3.8.5` с `deploy.py`,
`SHA256SUMS`, бинарником и bundle по существующему формату patch4.
`deploy.py` создаёт локальную резервную копию, обновляет только панель и bundle,
проверяет локальный HTTP-ответ панели и откатывает бинарник при сбое установки.
Xray и конфигурация туннелей не заменяются. Результат записывается в существующий
update-status с исходным runId. Резервная копия содержит секреты и должна оставаться приватной.

При следующем выпуске обновите `forkReleaseTag` в `panel.go`; сохраните формат
архива и опубликуйте релиз как latest. Новая базовая версия требует отдельной
адаптации и проверки, не устанавливается автоматически поверх 3.8.5.
